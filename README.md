# goldseats-api

Backend for [GoldSeats](https://goldseats.app) — film catalog, theatre seating
layouts, and AI seat recommendations.

FastAPI + SQLAlchemy 2.0 + Alembic. Runs on a local SQLite file by default so
no Docker or database server is needed to get started; production points at
Postgres through a single environment variable.

## Quick start

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-dev.txt
cp .env.example .env
alembic upgrade head
uvicorn app.main:app --reload
```

- API: http://localhost:8000
- Interactive docs: http://localhost:8000/docs
- Health: http://localhost:8000/api/v1/health

## Layout

```
app/
  api/v1/        HTTP routes, one module per resource
  core/          settings and logging
  db/            engine, session, models
  domain/        business logic, no framework imports
  ml/            seat scoring service (M5)
  schemas/       Pydantic request and response models
alembic/         migrations
ml/dataset/      synthetic seat-map dataset generator
tests/           pytest suite
```

`app/domain` holds pure logic and must not import FastAPI or SQLAlchemy
sessions. Routes stay thin: parse, delegate, serialize.

## Database

`DATABASE_URL` selects the backend. Everything else is identical.

```bash
# local (default)
DATABASE_URL=sqlite+pysqlite:///./goldseats.db

# Postgres
DATABASE_URL=postgresql+psycopg://goldseats:password@localhost:5432/goldseats
```

Creating a migration:

```bash
alembic revision --autogenerate -m "add films table"
alembic upgrade head
```

Migrations run under SQLite in batch mode, which rewrites tables for ALTERs
SQLite cannot do natively. Keep migrations reversible and review autogenerated
output before committing — see
[database-conventions](../goldseats-docs/engineering/database-conventions.md).

## Seat scoring dataset

`ml/dataset/` generates synthetic auditoriums with ground-truth best seats,
used to train and evaluate the recommender. It has its own dependencies
(Pillow, numpy, pandas, matplotlib) which are not installed by default:

```bash
pip install -r ml/dataset/requirements.txt
python ml/dataset/generate.py --count 100 --output ml/dataset/output --preview
```

In M5 the scorer in `ml/dataset/generator/recommender.py` is promoted to
`app/ml/scoring.py` as the production service. In M2 the geometry logic in
`ml/dataset/generator/theatre.py` is reused for seeding real auditoriums so
seeded layouts match what the model was trained on.
